# Liv-in_Paris

Création d'une application de livraison de commandes entre des particuliers.

An application designed to facilitate order delivery services between individuals in Paris.

## 📋 Project Overview

Liv-in_Paris is a delivery service platform that connects individuals to share and fulfill delivery orders within the Paris area. The application enables peer-to-peer delivery coordination, making logistics more accessible and efficient for local communities.

## 🛠️ Technology Stack

This project is built with a diverse set of technologies:

- **C# (61.3%)** - Backend services and core application logic
- **T-SQL (36.8%)** - Database queries and data management
- **Python (1.9%)** - Utility scripts and data processing

## 🎯 Key Features

- User registration and authentication
- Order creation and management
- Delivery tracking and coordination
- Review and rating system
- Real-time notifications

## 📦 Requirements

### Backend (.NET/C#)
- .NET Framework or .NET Core
- Visual Studio or Visual Studio Code

### Database
- SQL Server (for T-SQL queries)

### Utilities
- Python 3.x (for helper scripts)

## 🚀 Getting Started

### Prerequisites
- Ensure .NET SDK is installed
- SQL Server instance configured
- Python installed (optional, for utility scripts)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Dm2004co/Liv-in_Paris.git
   cd Liv-in_Paris
   ```

2. Configure your database connection string in the application settings

3. Build the project:
   ```bash
   dotnet build
   ```

4. Run database migrations (if applicable)

5. Start the application:
   ```bash
   dotnet run
   ```
